# Competitive benchmark

The benchmark is vendor-neutral and fixture-driven. It measures Lyte itself:
time to first source/view/outcome mapping/evidence explanation/decision replay,
receipt/truth/source-binding completeness, query and ingest performance,
storage growth, keyboard completion, mobile overflow, bundle size, and resource
consumption.

Allowed labels are `MEASURED_ADVANTAGE`, `MEASURED_PARITY`, `MEASURED_GAP`,
`DOCUMENTED_DIFFERENCE`, `NOT_TESTED`, and `UNAVAILABLE`. A feature list or
visual opinion cannot produce an advantage label. Results include fixture hash,
source revision, environment, exact command, raw measurements, and limitations.
